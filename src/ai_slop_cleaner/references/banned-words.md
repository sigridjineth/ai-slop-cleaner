## Clichéd openers / transitions

Avoid these entirely:

- "In today's digital age"
- "It's important to note"
- "Furthermore"
- "Moreover"
- "However" (overused at paragraph start)
- "Not only this, but also this"
- "In conclusion"
- "In closing"
- "Let's dive in"
- "Let's explore"
- "It's worth noting that"
- "As we navigate"
- "In an era of"

## Stiff formal phrases

Replace with conversational equivalents:

| Stiff | Natural |
|-------|---------|
| "It is essential that" | "You need to", "Make sure" |
| "It should be noted" | (Delete) |
| "In order to" | "To" |
| "Due to the fact that" | "Because" |
| "With regard to" | "About", "Regarding" |
| "In the event that" | "If" |
| "For the purpose of" | "To" |
| "At this point in time" | "Now" |
| "In spite of the fact that" | "Although" |
| "In the absence of" | "Without" |
| "It is evident that" | "Clearly" |
| "It is apparent that" | "Apparently", "Clearly" |
| "There is a need for" | "We need" |
| "A significant number of" | "Many" |
| "A considerable amount of" | "Much", "A lot of" |

## AI hedge phrases

These make prose sound uncertain and machine-like:

- "It is interesting to note that"
- "One could argue that"
- "It is possible that"
- "There is a possibility that"
- "It may be worth considering"
- "Arguably"
- "Potentially" (when used as a sentence adverb)
- "In some cases"
- "To a certain extent"
- "By and large"
